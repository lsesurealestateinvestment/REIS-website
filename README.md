# REIS website — Stage 4

Static GitHub Pages website for the LSESU Real Estate Investment Society.

## Pages
- `index.html` — homepage
- `team.html` — 2026–27 committee and future archive
- `research.html` — research divisions and future publication archive

## Publishing
Upload the contents of this folder to the **root** of the `main` branch of `lserealestateinvestment/REIS-website`. Keep `team-photos/` as a folder. GitHub Pages serves the files automatically.

## Adding publications later
Only publish approved research. Add PDF reports to a `reports/` folder, then edit the Publications section in `research.html` to link the real file and its title, author, and date. Do not list unpublished reports as published.

## Annual committee handover
Before replacing the 2026–27 committee, preserve their names, roles and group photo in an archive section. Check consent and give at least two trusted committee members admin access to the GitHub repository.
